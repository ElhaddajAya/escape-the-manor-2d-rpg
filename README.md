# Escape the Castle – 2D RPG d’Horreur en Pixel Art

ccc

**Escape the Castle** est un jeu d’exploration et de survie en 2D, inspiré des classiques du RPG d’horreur. Plongez dans un manoir maudit, affrontez des créatures surnaturelles et découvrez les secrets enfouis depuis des siècles.

---

## 🎮 À propos du jeu

* **Genre :** RPG d’exploration, survie, horreur
* **Plateformes :** PC, Mobile
* **Moteur :** Unity
* **Graphismes :** 2D Pixel Art
* **Perspective :** Vue de dessus (Top-Down)

---

## 📜 Synopsis

Depuis des siècles, un ancien château isolé dans les montagnes est abandonné. Des rumeurs parlent d’un trésor caché dans ses profondeurs, gardé par des créatures terrifiantes : squelettes, démons, diables… Aucun aventurier n’est jamais revenu pour confirmer son existence.

Vous incarnez un jeune explorateur fasciné par les mystères oubliés. Un vieux manuscrit découvert dans une librairie poussiéreuse mentionne ce trésor perdu. Poussé par la curiosité et l’envie de gloire, vous décidez d’entrer dans ce manoir hanté.

Mais dès que vous franchissez la porte, vous comprenez que ce lieu est maudit. Des ombres vous surveillent. Les monstres rôdent dans les pièces sombres, prêts à vous attaquer à tout moment.

---

## 🕹️ Contrôles

| Touche | Action                        |   |
| ------ | ----------------------------- | - |
| ← / →  | Déplacement gauche / droite   |   |
| ↑ / ↓  | Monter / Descendre            |   |
| Espace | Attaque (Bâton sacré)         |   |
| E      | Interagir / Ramasser un objet |   |
| I      | Ouvrir l’inventaire           |   |
| 1-4    | Sélectionner un objet rapide  |   |

---

## 🔑 Mécaniques de jeu

* **Exploration non linéaire :** Certaines pièces nécessitent des clés ou objets spécifiques.
* **Visibilité réduite :** Le joueur ne voit qu’une partie de l’écran à cause de l’obscurité.
* **Système de combat :** Utilisez le Bâton Sacré pour affronter les ennemis.
* **Lecture de documents :** Découvrez des notes et livres anciens pour comprendre l’histoire du manoir.
* **Pièces verrouillées :** Nécessitent des clés spécifiques ou des codes trouvés dans les documents.
* **Gestion d’inventaire :** Utilisez des armes, potions et objets pour survivre.

---


## 🗝️ Objets et Power-ups

* **Bâton Sacré :** Permet d’exorciser les esprits.
* **Clés :** Ouvrent les pièces verrouillées.
* **Potions de santé :** Restaurent la santé du joueur.
* **Documents :** Notes et livres révélant l’histoire du château.

## 📂 Installation

1. **Cloner le dépôt :**

   ```bash
   git clone https://github.com/ElhaddajAya/escape-the-manor-2d-rpg.git
   ```

2. **Ouvrir le projet dans Unity :**

   * Lancer Unity Hub.
   * Cliquer sur "Add" et sélectionner le dossier du projet.
   * Ouvrir le projet.([gamedeveloper.com][4])

3. **Lancer le jeu :**

   * Cliquer sur "Play" dans l’éditeur Unity.([gamedeveloper.com][4])
